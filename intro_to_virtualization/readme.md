Задача 2
1. Для высоконагруженной базы данных Mysql, критичной к отказу, лучше всего подойдет физический сервер, который даёт максимальную производительность. Использование виртуализации создает виртуальные диски на ВМ, которые являются файлами на физическом хосте. Для работы с данными на накопителях это добавляет накладные расходы. Отказоустойчивость легко достигается на любой платформе.
2. Различные web-приложения покажут высокую эффективность, если они будут работать в виртуализации уровня ОС, когда на одном хосте можно запустить много контейнеров, каждый из которых изолирован. Web-приложения чаще всего это одна или несколько служб, которые слушают сетевой порт и обрабатывают запросы. Поэтому контейнеры подходит больше всего.
3. Windows-системы для использования бухгалтерским отделом лучше развернуть на паравиртуализационной платформе (например Hyper-V), которая позволит для каждого сотрудника отдела иметь свой рабочий стол благодаря службе RDS с сеансовым распрделением на одном физическом сервере. Также для этой задачи подходит паравиртуализационная платформ, т.к. пользвоателям неободим полный набор функционала ОС.
4. Системы, выполняющие высокопроизводительные расчеты на GPU будут работать эффективнее на физических серверах, где аппаратная часть не будет разделена на части.
